# SempreGanhe

SaaS web de promoções com raspadinha digital para fidelização de clientes de restaurantes.

## Estado atual

A fundação do projeto foi criada com o Vibe Coding Toolkit. O produto ainda está na etapa anterior à implementação das funcionalidades de negócio.

Leia [PRODUCT.md](PRODUCT.md) para o escopo e [docs/onboarding.md](docs/onboarding.md) para preparar o ambiente.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000`.

## Verificação

```bash
pnpm check
```

As migrações de banco só serão executadas quando o schema do domínio estiver definido e houver um PostgreSQL autorizado.
