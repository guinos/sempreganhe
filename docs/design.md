# Direção visual

## Princípios

- Mobile first: o fluxo público nasce para uso imediato após escanear um QR Code.
- A raspadinha é o foco visual da tela e deve comunicar claramente o próximo passo.
- O resultado e o cadastro devem ter estados de carregamento, erro e sucesso visíveis.
- Formulários devem ter labels, foco visível, contraste adequado e mensagens junto aos campos.
- Animações devem respeitar redução de movimento e não impedir o acesso ao prêmio.

## MVP

Não há biblioteca de componentes adotada ainda. A interface será feita com HTML acessível e Tailwind, adicionando componentes compartilhados apenas quando um fluxo real justificar.
