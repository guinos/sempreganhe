# Iconografia — piloto v0.1

- Base: grade 24×24 px.
- Estilo: preenchido para prêmio/celebração; outline arredondado para navegação e operação.
- Stroke: 2 px, caps e joins arredondados.
- Ícones prioritários: `scratch-card`, `star-prize`, `gift`, `ticket`, `qr-code`, `restaurant`, `sparkle`, `check`, `lock`.
- Ícones funcionais devem acompanhar texto ou label acessível.
- Nunca comunicar sucesso/erro apenas por cor.

## Ícones proprietários

- `icon-scratch-card`: cartão com camada parcialmente removida.
- `icon-swipe-finger`: dedo sobre a superfície, reservado para onboarding e instrução.
- `icon-revealed-prize`: estrela surgindo por baixo da camada.
- `icon-promo-game`: composição reduzida dos três elementos para campanhas.
