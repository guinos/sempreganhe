# Logo SempreGanhe — v0.2

Versão vetorial baseada na referência visual aprovada em `brand-reference.md`.

## Arquivos

- `sempreganhe-primary.svg` — versão horizontal colorida.
- `sempreganhe-stacked.svg` — versão empilhada para peças verticais.
- `sempreganhe-mark.svg` — símbolo do cartão raspado para favicon/avatar.
- `sempreganhe-monochrome.svg` — versão branca para fundos escuros.

## Regras iniciais

- Usar a versão horizontal como padrão em headers e materiais largos.
- Usar o símbolo sozinho apenas quando o contexto já identificar a marca.
- Manter área livre mínima equivalente à altura do dedo ao redor do logo.
- Não esticar, girar, aplicar sombra externa adicional ou alterar as cores do wordmark.
- Tamanho mínimo sugerido: 180 px de largura na versão horizontal e 32 px no símbolo.

Estes SVGs são a primeira consolidação vetorial e devem ser revisados visualmente antes de serem considerados o master definitivo.
